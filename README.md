# Gym

Gym Tracker: Android-App fürs Training, Essen und Erholung. Der Code liegt im Ordner [`gym-tracker-app`](gym-tracker-app/README.md).

**App herunterladen:** rechts unter **Releases** die neueste `gym-tracker-v….apk` laden und installieren.

Änderungen am Code baut GitHub Actions automatisch. Vor dem ersten Bau muss das Secret `ANDROID_KEYSTORE_BASE64` angelegt sein, siehe [gym-tracker-app/README.md](gym-tracker-app/README.md#signaturschlüssel-wichtig-für-updates-ohne-datenverlust).
